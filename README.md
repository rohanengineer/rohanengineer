### 🚀 Featured Project

#### [QueueForge — Distributed Task Queue & Job Processing Platform](https://github.com/rohanengineer/queueforge)

A distributed asynchronous job-processing platform built to explore backend engineering and distributed-systems concepts.

- **Asynchronous processing:** Separates job submission from background execution using a producer-consumer architecture
- **Reliability:** Includes automatic and delayed retries, exponential backoff, and a dead-letter queue for jobs that exhaust their retries
- **Worker monitoring:** Tracks worker heartbeats and worker availability
- **Live dashboard:** Displays job and worker metrics with real-time updates over WebSockets
- **Tech stack:** Node.js, TypeScript, Express.js, Redis, MongoDB, Next.js, React, Socket.IO, Docker Compose
